# GARUDA AI

## AI-Driven Crime Pattern Analysis and Public Safety Intelligence System

GARUDA AI is an AI-driven public safety intelligence system designed to analyze crime patterns using machine learning, spatial and temporal analytics, multi-level cross-verification, explainable AI, and security mechanisms.

## Project Structure

- `data/` — Dataset storage and processed data
- `docs/` — Project documentation and architecture
- `notebooks/` — Exploratory and experimental notebooks
- `src/` — Source code
- `models/` — Trained model artifacts
- `results/` — Experimental results and comparisons
- `reports/` — Figures, tables and research outputs
- `dashboard/` — Public safety intelligence dashboard
- `tests/` — Testing
